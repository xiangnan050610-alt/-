# GitHub真实成像与Prompt强化

## 光线六问
光源是什么 → 从哪里来 → 大小/距离 → 软硬 → 强弱/对比 → 阴影/高光如何响应。

进一步检查：环境反射、人物受光、背景受光、色温是否一致。

## 成像维度
动态范围、黑位、白位、高光滚降、锐度、微对比、颗粒、噪声、压缩感、镜头散射、光晕、景深、焦外。

## 场景匹配
- 普通手机记录：允许轻微曝光波动、合理自动白平衡倾向、有限动态范围、自然锐度和环境底噪；避免广告片式完美布光。
- 电影摄影：可有明确的光源设计、景深控制和稳定曝光，但仍需保持光源物理合理。
- 纪录片/调查：优先真实环境光和观察式机位，减少不必要的“完美轮廓光”。
- 动画/CG：真实感来自材质、几何、光照和渲染一致性，不等同于真人摄影。

## AI感诊断
常见来源：
1. 人物曝光与背景不一致；
2. 脸部独立发亮；
3. 无光源依据的轮廓光；
4. 皮肤纹理均匀贴图；
5. 材质粗糙度完全一致；
6. 景深/运动模糊与摄影机运动不匹配；
7. 背景透视、反射或阴影不符合空间。

## Prompt原则
不要把“电影级、8K、超真实”当成解决方案。优先描述产生该质感的摄影与物理条件。


## 视频对照案例增补：细节可读性与暖色协调分开控制（2026-10-10）

参考案例：`14-参考视频逆向分析库/14-双视频质感对照案例_V10.17与候选版.md`。

- A（V10.17 原版）作为面部细节/微结构优先样本：强调适度微对比、稳定对焦、局部纹理可读性，不推断具体相机参数。
- B 作为暖色调协调的辅助样本：可借鉴人物与环境的色温衔接，但不得让暖色滤镜吞掉皮肤结构。
- 微对比不等于全局高反差；保留眼窝、鼻翼、下颌阴影中的肤色信息，并让高光柔和滚降。
- 人物曝光、光向、色温应与环境匹配；不要单独提亮脸部或无依据地添加轮廓光。
- 近景允许更多细节可读，中远景纹理应随距离自然减弱。
