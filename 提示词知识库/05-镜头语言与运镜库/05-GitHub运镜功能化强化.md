# GitHub运镜功能化强化

## 总原则
先确定剧情功能，再选择运动；禁止先选炫技运镜再硬套剧情。

## 运镜选择维度
- 建立空间：缓慢横摇、轻微后拉、稳定跟拍。
- 跟随动作：Tracking/Dolly/Truck等真实位移。
- 揭示信息：Push-in、Pan、Rack Focus等。
- 拉近心理距离：缓慢Push-in或轻微Dolly-in。
- 制造不安：不稳定手持、短促推进、有限焦段变化。
- 表现权力/尺度：低机位、后拉、升降。
- 转场：遮挡、运动方向匹配、自然景物掠过。

## 每次运镜必须说明
起幅主体 → 摄影机实际路径/镜头变化 → 方向 → 速度/加速度 → 途中信息 → 落幅主体/构图 → 为什么此刻运动。

## 现实摄影约束
- 不把Pan/Tilt/Zoom写成摄影机空间移动。
- 同一短镜头不要同时堆叠多个主运动。
- 人物运动速度与摄影机追踪速度要匹配。
- 运动需要有惯性/启动/停止逻辑时，加入轻微加减速，而非瞬移。
- 静态镜头本身可以成立；不要为了“高级感”强制运动。
