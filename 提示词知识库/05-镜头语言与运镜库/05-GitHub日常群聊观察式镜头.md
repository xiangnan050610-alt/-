# 日常多人聊天：观察式镜头语言

## 推荐策略
- 以中景或中远景建立人物群体和村口空间，再通过轻微平移/小幅调整构图跟随说话者，不必频繁正反打。
- 人物聊天是群体日常时，机位可略带观察感，像旁边熟人随手记录；构图允许轻微不完美，但不能遮挡关键人物或导致空间关系混乱。
- 8秒短片优先一个连续镜头；只有情绪、信息或说话对象明显变化时才切镜。
- 运镜起点、过程、终点要有理由：例如开场覆盖三人，第一位说话时轻微偏向她，另一位笑着接话时再调整构图，最后回到群体反应。

## Blocking
- 明确每位妇女的画面左右位置、彼此距离、面向与视线。
- 说话者用自然手势、点头或轻微转身提示发言；听者以短暂目光、微笑、轻轻摇头或回应动作表现倾听。
- 不要所有人同时做大动作或同时看镜头。

## 8秒节奏建议
0–2秒：先呈现群体和地点，聊天已自然开始。
2–5秒：一人说一小句，另外一人以眼神或轻笑回应。
5–8秒：第三人补一句或做生活化反应，话题自然延续，不必强行收尾。

## 避免
- 每个人轮流机械地看镜头说话。
- 无缘无故快速推拉、环绕、升降。
- 8秒塞入过多台词导致口型赶拍。
- 对话结束后所有人同时定格或同步微笑。
