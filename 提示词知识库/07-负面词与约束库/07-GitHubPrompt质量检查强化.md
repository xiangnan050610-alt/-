# GitHub Prompt质量检查强化

## 约束优先级
身份/人脸/空间/核心动作/时间连续性 > 摄影机与Blocking > 光线 > 皮肤与材质 > 色彩 > 风格装饰。

## 常见冲突
- 固定镜头 + 环绕镜头
- 缓慢动作 + 同时高速运动
- 单一人物 + 无意加入第二人物
- 同一物体位置前后矛盾
- 光源方向与阴影方向冲突
- 参考视频未说明具体参考变量
- 8秒塞入无法完成的多段剧情
- 把“电影感”当成光线描述

## 最终QC
- 单镜头主动作是否明确？
- 动作是否有起点/终点？
- 参考素材是否逐一说明用途？
- 运镜是否有动机？
- 光线是否有来源？
- 人物与环境是否共享同一曝光/色温逻辑？
- 是否有不必要的修饰词？
- 负面词是否只约束真正高风险错误？
