# GitHub视频逆向分析方法论

## 目标
把参考AI视频拆解为“可观察证据 → 摄影控制变量 → 视觉质感变量 → 人物表演变量 → 时间轴 → Prompt描述”。

## 六层逆向框架
### L1 时间轴/镜头边界
记录每个明显镜头的开始、结束、持续时间、切镜点、主体变化。

### L2 摄影机
记录景别、机位高度、拍摄方向、焦距感觉、摄影机是否位移、运动方向、速度、起落幅、对焦变化。

### L3 光线与成像
记录主要光源、方向、大小/软硬、对比度、阴影、高光滚降、色温、黑位/白位、颗粒、噪声、锐度、微对比、镜头散射等。

### L4 人物
记录身份特征、姿态、视线、动作起止、表情变化、反应延迟、接触关系、衣物运动。

### L5 环境与材质
记录空间结构、透视、背景虚化、反射、材质粗糙度、使用痕迹、环境动态。

### L6 声音
记录台词时间、语速、停顿、呼吸、环境底噪、动作音、音乐与画面节奏关系。

## 证据等级
- OBSERVED：视频中直接可见/可听。
- INFERRED-HIGH：多项可见证据共同支持。
- INFERRED-MID：合理推断，但存在其他成因。
- HYPOTHESIS：仅候选解释，不进入核心规则。

## Prompt反推
先写观察事实，再映射到可能控制变量。例如：
“人物脸部高光柔和、鼻翼与额头有轻微油光、阴影边缘软” → “大面积柔光源、较低局部对比、皮肤保留自然高光”。

不要直接把“看起来像某相机”当作确定事实；应记录为镜头/成像风格推断。

## 参考视频→知识库
逆向结果可分别归档到：
14时间轴/逆向案例 → 05镜头 → 04成像光感 → 03皮肤 → 06表演 → 09环境 → 10摄影参数 → 16材质 → 18 Visual DNA。

## 逆向分析输出检查
- 是否区分观察与推断？
- 是否覆盖时间、镜头、动作、光线、皮肤、材质、声音？
- 是否存在“AI感”来源分析？
- 是否能把结论转成可执行Prompt，而不是只写审美评价？
