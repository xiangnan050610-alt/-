# GitHub方法论：Visual DNA与连续性

## Visual DNA
Character｜Wardrobe｜Scene｜Camera｜Lighting｜Color｜Skin｜Material｜Motion｜Audio｜Reality。

## 每个项目建立
### 固定项
人物身份、年龄感、脸型五官、身体比例、核心服装、固定道具、场景结构、基础色彩、默认成像倾向。

### 可变项
情绪、动作、光照强度、时间、镜头景别、运镜；每次变化必须有剧情/物理原因。

### 连续性检查
- 跨镜头脸型/年龄感/肤色是否漂移？
- 光线变化是否能由时间/位置/光源解释？
- 衣物、道具是否有合理变化？
- 镜头变化是否改变了空间左右关系？
- 皮肤、颗粒、动态范围是否突然换了一套世界？

## Production Bible
记录项目总基调、人物DNA、场景DNA、镜头DNA、光线DNA、色彩DNA、皮肤DNA、材质DNA、声音DNA、允许变化范围与禁止变化项。

## 应用
多镜头/连续剧任务先读取18，再按当前镜头读取具体分类；18负责“保持什么”，具体分类负责“这一镜怎么拍”。
