# 多人日常交谈：表情与动作变化链

## 核心原则
日常聊天情绪幅度小，使用细微且不完全同步的反应，不调用夸张戏剧化肌肉链。

## 说话者变化链
听取前一句 → 眼神转向对方 → 嘴角/眉部出现轻微变化 → 自然开口 → 说话时有小幅头部或手部动作 → 句末停顿/呼吸 → 目光回到听者。

## 听者变化链
注意力转向说话者 → 0.1–0.4秒自然反应延迟 → 轻微点头、短促笑意或略微挑眉 → 视线短暂离开再返回 → 准备接话。

## 北方农村日常交谈适配
- 可用自然、直接、熟人之间的语气；具体口音和方言强度未知时，不强行拼写夸张方言字。
- 手势以生活化的小动作呈现，如手里拿着布袋、轻轻指一下村道、整理袖口、扶住自行车把手。
- 表情可以亲切、好奇、略带打趣，但不把普通聊天自动变成争吵或夸张喜剧。
- 不要求所有人物都持续微笑；听者可边听边看周围、点头或短暂皱眉思考。

## 连续性约束
说话者的口型与台词对应；非说话者不要同步张嘴。手中物件不能无故换手、消失或变形；人物视线与彼此站位一致。
