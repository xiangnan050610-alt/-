# minimax提示词 V20.0 视频逆向拆解强化模块

> 本文件是对现有 minimax提示词 V19.0 双路知识库 Skill 的增量升级模块。
> 原V19工作流程、标准输出模板、时间轴、优先级与末尾顺序不删除、不改写；本模块只增加“参考AI视频逆向分析、知识拆解、缺口审计、18类知识库路由”。

## 1. 视频逆向分析总流程

读取视频 → 建立时间轴 → 抽取关键帧 → 场景切分 → 人物/空间锁定 → 摄影机分析 → 光线分析 → 成像/画面质感分析 → 皮肤分析 → 材质/纹理分析 → 表演/动作/口型分析 → 色彩/色卡分析 → 声音分析 → Prompt结构反推 → 知识分类映射 → 缺口审计 → 来源采集 → 标准化归档。

## 2. 证据分层

### OBSERVED
视频中直接看到的事实：景别、构图、光源方向、色彩、皮肤、服装、动作、场景、声音等。

### INFERRED-HIGH
多项视觉证据共同支持的高概率生成控制，例如自然窗光、浅景深、低对比度、现实皮肤、情绪状态机。

### INFERRED-MID
合理但存在其他解释的推断。

### HYPOTHESIS
仅作为候选Prompt，不得写成“原Prompt就是这样”。

## 3. Prompt逆向骨架

主体身份 → 场景/空间 → 起始状态 → 情绪起点 → 情绪变化链 → 动作链 → 台词/声音 → 景别/机位 → 运镜 → 光源 → 光线结构 → 色彩/色卡 → 成像系统 → 皮肤 → 材质/环境反应 → 时间锚点 → 约束。

## 4. 情绪状态机

当视频表现出连续情绪变化时，优先建立：

情绪1 → 情绪2 → 情绪3

必须明确：
- 开场状态；
- 每个情绪的触发；
- 变化顺序；
- 禁止提前发生；
- 禁止多个状态同时出现；
- 结束状态。

本轮参考视频教学页直接展示了“先写情绪顺序和起点”，并要求情绪按顺序发生；开场状态可明确为眼睛干、表情冷/平静。该方法进入 06 与 13 知识库。

## 8. 知识缺口审计

每次扩库必须检查：

定义 / 属性 / Prompt词汇 / Prompt句式 / 适用场景 / 不适用场景 / 正例 / 反例 / 失败案例 / 参数 / 图片参考 / 视频参考 / 来源 / 日期 / 可信度 / 跨库依赖。

发现只有形容词时，继续拆成可执行视觉属性。
发现只有图片时，建立“图片 → 视觉属性 → Prompt描述”。
发现只有文字时，补充真实视觉案例。
发现单一来源时，寻找专业来源+真实案例交叉验证。

## 9. 参考视频归档格式

视频编号 → 时间码 → OBSERVED事实 → INFERRED生成控制 → Prompt候选写法 → 对应知识库 → 子分类 → 适用场景 → 反例 → 置信度 → 来源/证据。

## 10. 本轮视频样本归档

样本：Record_2026-10-05-10-47-12_2332cb9b27b851b548ba47a91682926c.mp4，约41.14秒。

观察：
- 汽车内部；
- 男女双人对话；
- 中近景/近景面部覆盖；
- 车内座位附近视点；
- 车窗外城市/绿化浅景深；
- 日间自然环境光；
- 低至中对比度；
- 灰色车内饰；
- 人物皮肤自然柔和、无强玻璃肌；
- 情绪变化通过眼神、嘴部、头部与整体表演推进；
- 字幕/水印属于后期包装层，不默认写入生成Prompt。

高概率控制：
- 现实主义车内双人对话；
- 交替近景/正反视角；
- 浅景深但保留车内空间信息；
- 自然窗光与人物共享曝光、色温；
- 自然皮肤；
- 情绪状态机。

不可确认：
具体相机型号、真实焦段、光圈、ISO、seed、采样参数、模型内部权重与隐藏控制参数。
