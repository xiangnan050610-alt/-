# GitHub皮肤与环境成像联动强化

## 皮肤不是独立贴图
皮肤描述必须同时考虑：
基础肤色 → 微结构 → 局部区域 → 生理状态 → 反射 → 光线响应 → 成像。

## 真实皮肤控制
可观察维度：
- 毛孔大小与分布
- 细小皮纹
- 毛囊/汗毛
- 额头/鼻翼/下巴皮脂
- 眼周细纹
- 干燥、出汗、泛红、疲惫、运动后状态
- 高光宽度与滚降
- 阴影中的皮肤色彩保留

## 场景联动
室内暖灯、窗光、阴天、霓虹、手机直出、纪录片、电影摄影会产生不同的皮肤呈现；不要给所有场景套同一套“毛孔+4K皮肤”。

## 反AI原则
避免：
- 玻璃肌
- 塑料肌
- 统一大小/均匀分布的毛孔
- 过度磨皮
- 脸部与手部肤质不一致
- 皮肤纹理强到像贴图

## 近景调用
面部特写时：先查本库，再查06表情/生理，再查05镜头；人物连续性则补查08。
