## 职责边界

导演 Skill 负责故事前提、主题、人物目标与内在冲突、场景戏剧结构、对白、剧集结构、短剧节奏、镜头/表演/视听决策和制作交接。它可以输出供提示词 Skill 使用的创作方案，但不得替换或改写提示词 Skill 的原有输出模板。

导演 Skill 已覆盖的镜头、摄影、光影、分镜、连续性、提示词和诊断模块不重复复制；补充资料只填补明确缺失的故事开发与短剧结构能力。
