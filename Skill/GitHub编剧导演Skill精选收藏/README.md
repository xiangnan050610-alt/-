## 给 Reality Cinematic Engine 的使用建议
1. 编剧任务优先检索 screenwriting-skills 的结构、人物、对白和工作流文件。
2. 导演与分镜任务优先检索 DirectorSKILL 及 AI Film Skills 的导演 Agent / 分镜文件。
3. 视频提示词、角色场景连续性和失败修复，优先检索 director-skills 的对应模块。
4. 这些文件只作为参考资料，不得直接覆盖现有 Reality Cinematic Engine 的模板、流程或输出框架；先分析差异，再以独立补充模块吸收。
5. 每次调用应读取相关原始 SKILL.md 与必要参考文件，不要只看 README 就宣称完整执行技能流程。
