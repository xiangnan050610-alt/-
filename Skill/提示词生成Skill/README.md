# 提示词生成 Skill

本文件夹只管理 AI 视频提示词生成流程与版本，不存放导演 Skill 主文件，也不替代「提示词知识库」。

## 当前入口

- [主版本：Reality Cinematic Engine V10.21](./Reality_Cinematic_Engine_Master_SKILL_V10.21_GitHubKB_最高铁律锁定版.md)
- [历史版本目录](./历史版本/)

## 职责

1. 遵循既有提示词生成流程、固定模板和输出框架。
2. 按镜头/场景条件检索仓库根目录「提示词知识库」中的对应分类。
3. 详细描述人物、动作、表情变化、环境、光线、材质、摄影质感和连续性。
4. 交付时遵守主 Skill 中的固定输出结构，不自动添加与用户需求无关的说明或模型版本分支。

## 与导演 Skill 的边界

导演 Skill 负责故事与导演决策；本 Skill 负责将已确定的创作意图转换为生成提示词。两者通过明确的交接信息协作，不合并模板。

维护约束：历史版本仅做归档，不覆盖主版本；优化只增补完善，不擅自删减原有内容。
