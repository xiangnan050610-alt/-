# 一、强制工作流程（细致化编程式）
# ============================================================

1. **读取本Skill**：确认核心原则、写前分析、标准模板、优先级、末尾顺序。
2. **分析用户输入**（剧本/参考图/视频/需求）：
   - 提取场景、人物、关系、情绪弧线、事件、时间线。
   - 确定需要的知识类别列表。
3. **按条件查询GitHub知识库**：
   - 面部特写/近景情绪 → 先查`03-皮肤质感库` → 再查`06-肌肉与生理+表情变化链库` → 再查`05-镜头语言与运镜库`确认焦距/机位 → 涉及人物连续性时查`08-人物资产与一致性库`
   - 全身/中景动作 → 先查`02-姿势与情节库` → 再查`01-穿搭风格库` → 再查`05-镜头语言与运镜库`
   - 需要画面质感/光感/色卡 → 查`04-画面质感与光感库`，必要时补查`09-场景与环境质感库`、`10-摄影机参数库`
   - 需要负面词 → 查`07-负面词与约束库`
   - 涉及固定人物、跨镜头或跨集连续性 → 查`08-人物资产与一致性库`
   - 涉及具体环境 → 查`09-场景与环境质感库`
   - 需要摄影设备/参数依据 → 查`10-摄影机参数库`
   - 需要公开参考资料 → 查`11-参考案例与资料链接库`
4. **设计摄影机路线与时间锚点**（本Skill内完成）。
5. **按标准模板整合输出**（只输出提示词本身）。
6. **末尾强制**：皮肤质感 → 画面质感（光感并入）→ 负面词。


### GitHub优秀Prompt方法论增量路由（不改变原流程，只增强原步骤）
在原有第2-5步内部增加以下检查：
- 若任务涉及短剧叙事/情绪可视化：补查`11-GitHub优秀AI视频Prompt资源总库`，吸收“抽象剧情→可见行为”的方法。
- 若任务涉及8秒以上、复杂动作或多镜头：补查`13-AI视频提示词结构与时间轴库`，执行“起始状态→变化链→结束状态”的时间轴检查。
- 若用户提供参考视频：强制补查`14-参考视频逆向分析库`，先区分OBSERVED / INFERRED-HIGH / INFERRED-MID / HYPOTHESIS，再把可确认结论路由到05/04/03/06/10/16/18。
- 若涉及运镜：补查05中的“功能化运镜”知识；先确定剧情功能，再选运动。
- 若涉及真实感/AI感：补查04与03，检查人物和环境是否共享曝光、色温、光线、成像与皮肤逻辑。
- 若涉及连续剧/连续镜头：补查18，先锁定Visual DNA固定项，再处理本镜可变项。
- 输出前增加一次Prompt QC，但**只作为原有质量自检的增量项，不改变原质量自检结构**。

# 二、核心原则（流程级，保留）
# ============================================================

生成的每一条提示词必须满足：信息整合不分散、时间线明确、运镜有动机、镜头参数可执行、人物空间关系清晰、人物情绪与内心动态明确、动作与台词时间对应、人物细节按需展开、画面质感服务场景、光线逻辑可解释、皮肤质感与光线匹配、同剧视觉基调稳定、负面词约束到位、可直接复刻。

- 运镜有动机：由人物注意力、动作、情绪变化或信息揭示触发。
- 镜头参数可执行：景别、机位、位置、高度、方向、焦距、光圈、景深、焦点、构图按需明确。
- 人物信息可控：景别决定颗粒度。
- 情绪先有因果再有外化。
- 动作与台词同步：关键动作绑定秒数或台词字词。
- 画面质感按需调整：无固定全片模板。
- 同剧视觉稳定：允许合理变化。
- 质感与叙事优先级：身份与空间连续性 > 情绪可读性 > 真实光线逻辑 > 装饰性电影感。

第5步：设计时间锚点（关键动作绑定秒数或台词字词）。

# 五、描述规范与优先级（流程级）
# ============================================================

## 5.1 时间与分段
- 每个镜头通常3-15秒，对话必须覆盖完整台词+口型+动作+反应。
- 关键动作优先绑定具体秒数或台词字词。

## 5.2 人物动作与表情描述顺序（按需展开）
- 表情推荐：头部面向 → 内心情绪 → 眼神 → 眼轮匝肌 → 眉鼻口周 → 脸颊（查06）。
- 动作推荐：身体面向 → 头部 → 胸腔 → 腹部 → 手臂 → 手掌手指 → 腿部 → 脚部。
- 仅在近景/特写+中高情绪时进入具体肌肉（查06），禁止清单式同时触发。
- 允许0.1-0.4秒微不同步与反应延迟。

## 5.3 空间与轴线
- 先锁定人物左右、前后、距离、面向、视线。
- 默认保持180度轴线。
- 正反打保证视线方向与鼻前空间对应。

## 5.4 运镜规范
- 必须有触发。
- 写清起幅→过程（含惯性/延迟）→落幅。
- 具体类型查GitHub 05。

## 5.5 优先级（冲突时）
P0：人物身份、人脸与关键五官、年龄感、身体比例、核心动作、核心剧情、左右关系、视线、空间结构、关键道具、关键进出方向。
P1：摄影机位置、景别、焦距感觉、景深、运镜路线、光源方向、人物受光、情绪转折、Blocking。
P2：皮肤微结构、发丝、衣物纤维、材质反射、空气感、颗粒、色彩关系。
P3：电影氛围、艺术风格。
P4：装饰性信息。

冲突解决：人物身份 > 核心动作 > 空间与方向 > 时间连续性 > 摄影机 > 光线 > 皮肤与材质 > 色彩 > 风格 > 装饰。

## 5.6 末尾顺序（强制）
皮肤质感 → 画面质感（光感并入）→ 负面词。
负面词整场只写一次。

# 八、空间透视与三维纵深控制（增量规则，不改变原模板）

- 真实场景先建立“摄影机—人物—道具—地面—背景”的三维关系，再描述皮肤、材质、光影和风格。
- 按镜头需要明确：摄影机位置/高度/方向；主体与关键道具的远近层级；物体在画面中的宽高/面积占比；左右前后方位和朝向；透视线/消失方向；透视缩短与投影形状；遮挡顺序；地面接触点；景深与背景细节；运动时近中远景的相对视差。
- “近大远小”必须落实到具体对象：说明哪个近处物体相对哪个远处物体更大、同类结构如何随距离缩小，以及必要时的画面占比或大致距离锚点。数值用于帮助建立关系，不得伪装成精确测量。
- 透视必须与机位、主体距离、焦距/视角、拍摄方向和景别兼容。区分透视变化与镜头畸变；没有明确风格需求时，不得靠鱼眼、弯曲建筑或拉伸肢体制造空间感。
- 人物脚底、车轮、桌腿等必须正确接地；人物与物体互动须明确接触点、前后关系和遮挡，避免悬浮、穿插、贴图感。
- 有运镜时说明近景、主体和背景的相对运动差异；固定机位可用尺寸递减、透视线、遮挡、前后错位和接触关系建立纵深，不为“空间感”强行加运镜。
- 触发检索：`提示词知识库/19-空间透视与三维纵深库/19-空间透视与三维纵深控制规范.md`。涉及机位/焦距/运镜仍查05与10；建筑环境查09；人物和物体动作查02。新增分类是原有检索链的补充，不得替代原分类。

# 九、空间关系反推与连续性验证闭环（V11新增）

## 9.1 工作原则

- 不能只从“我想描述什么”正向写提示词，还必须从“最终画面应该呈现什么空间证据”反向验证。
- 空间关系属于高优先级约束，与人物身份、核心动作同级；材质、皮肤、光影不能掩盖错误透视。
- 本模块是原有写前分析与质量自检的增量层，不替换、不重排原有模板和流程。

## 9.2 四阶段闭环

**A. 正向空间规划**
1. 确定摄影机位置、高度、朝向、观察角度和景别。
2. 将主要人物、关键道具、地面、建筑和背景分为前景/中景/远景。
3. 为关键物体写出大致距离、画面占比、方位、朝向和遮挡顺序。
4. 选择至少两种相互印证的纵深线索：近大远小、透视线、遮挡、地面接触、清晰度层级、运动视差。
5. 说明哪些同类物体可用于校验尺度递减，例如门窗、路边电线杆、车轮、人物。

**B. 从成片画面反推**
- 反问：如果摄影机确实位于所描述的位置，画面中哪些边线应当收敛？哪些物体应该更大？哪些表面应该被缩短？
- 反问：如果道具位于人物前方，遮挡关系和相对尺寸是否支持这一判断？
- 反问：如果人物站在道路某一深度，脚底在画面中的落点是否符合地面平面和道路延伸方向？
- 反问：如果摄影机移动，近处物体与远处背景的相对位移是否支持所写的运镜？
- 对每个主要判断，尽量找到第二个空间证据交叉验证；若只有单一线索，避免写成过度确定的几何结论。

**C. 连续镜头/跨镜头验证**
- 同一空间的机位改变时，建筑、道路、家具和固定道具应保持同一三维布局；改变的是观察角度和投影，不是物体任意换位。
- 同一人物在不同景别中，身高与身体比例保持一致；画面占比可随距离和景别改变，但变化方向必须合理。
- 同一物体在近景、中景、远景中的尺寸变化，应能由摄影机距离、焦距/视角和构图解释。
- 镜头切换后检查屏幕方位、视线、180度轴线、进出方向、遮挡顺序和背景线条是否冲突。
- 若采用长焦压缩、广角近距离透视或明显机位变化，必须让该选择解释画面尺度差，而不是与空间描述互相矛盾。

**D. 纠错与重写**
发现空间冲突时，按以下顺序修正：
1. 先修摄影机位置、高度、方向和主体距离；
2. 再修人物/道具的三维站位、方位、朝向和遮挡；
3. 再修画面占比、透视线、投影形变和尺度递减；
4. 再修焦距/视角、景深和运镜路线；
5. 最后才微调光影、材质、皮肤和风格描述。
禁止用“更真实”“电影感更强”“加强空间感”等空泛形容词代替几何纠错。

## 9.3 空间冲突检测清单

- [ ] 距离与画面大小是否矛盾（近物却过小、远物却异常巨大）？
- [ ] 同类物体是否出现合理的透视尺度递减？
- [ ] 道路、墙根、屋檐、桌边和地面是否有相容的透视方向？
- [ ] 物体朝向是否与可见正面/侧面、梯形缩短或椭圆投影一致？
- [ ] 人物、道具、建筑的前后关系是否被遮挡证据支持？
- [ ] 人物脚底、车轮、桌腿等是否位于同一可解释地面平面？
- [ ] 近景/中景/远景层级是否至少有两种空间证据相互支持？
- [ ] 运镜中近景与背景的相对位移是否符合视差规律？
- [ ] 连续镜头中的固定场景物件是否保持三维位置稳定？
- [ ] 是否错误地用背景虚化替代透视、遮挡和尺寸关系？
- [ ] 是否出现没有明确创作意图的鱼眼畸变、弯曲建筑、拉伸肢体？
- [ ] 空间问题是否在皮肤/光影/质感优化之前得到解决？
